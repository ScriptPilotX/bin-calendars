# Bin Calendars

Public iCalendar feeds for bin collection schedules.

## Feeds

- Ealing Home: https://scriptpilotx.github.io/bin-calendars/ealing-12058663.ics
- CD: https://scriptpilotx.github.io/bin-calendars/cd.ics
- BA: https://scriptpilotx.github.io/bin-calendars/ba.ics

All feeds project 365 days ahead from the Ealing Council collection pattern and refresh daily at 06:00 (Europe/London) via a cron job on the Pi (`scripts/publish_to_github.sh`).

GitHub Pages publishes this repository from the `main` branch `/docs` folder.
